# Habit Tracker

A Habit Tracker application made using HTML, JavaScript, Tailwind and Node.js

## Set Up

1. Copy `.env.example` to a new file named `.env`
2. Add the MongoDB connection string to `MONGODB_URI` in the `.env` file.
3. Add a random secret to `JWT_SECRET` in the `.env` file.
4. Run `npm install`.

## Running the Application

### Development

To run the applicaion in development mode use `npm run dev`

### Production

To run the application in production mode use `npm start`
